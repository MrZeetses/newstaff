# L'AURUM ERP — Сайт №2: Корпоративная система Персонала (`site-2-staff-erp`)

Отдельный репозиторий внутренней системы управления рестораном **L'AURUM** (Бухгалтерия, Поставки, Экран Повара KDS, Официант/Хостес, Дашборд Босса с созданием сотрудников), работающий на **единой облачной базе данных Supabase** совместно с первым репозиторием для гостей (`site-1-guest`).

## 🚀 Как залить во 2-й репозиторий на GitHub Pages
1. Создайте на GitHub второй репозиторий (например, `laurum-staff-erp`).
2. Загрузите в корень репозитория файлы из этой папки `site-2-staff-erp/`:
   * `index.html`
   * `js/config.js` (ваш ключ `sb_publishable_Q8bp5yDcT3g-b0K7tnvbfw_RYFYDkMi` уже встроен!)
   * `js/core.js`
3. В файле `js/config.js` (строка 13) укажите тот же самый `SUPABASE_URL`, что и в первом репозитории.
4. Включите **Settings → Pages → Branch: main (/root)**.
